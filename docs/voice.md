# 对外发布文案风格 v3

2026-10-18 起，X 推文，Release 正文，以及其他对外发布的文本一律按本文写。旧的教程腔（「本质原因」「解决方案有 N 种」「推荐顺序」）停用。

完整版和样本在 Notion「BK 的写作风格」页顶部。

## 结构

一句定性开头，带数字和时间的事实，递进或反转，收尾。

- 第一句是短的态度判断，口语，可倒装，不铺垫。例：「太魔幻了。」「火力全开了这是。」
- 正文写具体身份，具体时间，具体数字。用「然后」「而且」「结果」推进，一段一个信息点。
- 需要解释的词用中文括号就地补一句。
- 最有反差的事实放最后。结尾最多一个表情（常用 🤣 🙃），不写互动号召，不加话题标签，链接放最末。
- 有争议的事改用编号短句，一条一个事实，分号断开。
- 写自己的事极简，三行内，逗号断出节奏。

## 排版

- 只用中文标点，不出现英文逗号，破折号，引号。
- 中文与数字，中文与英文之间加半角空格：「56 岁」「v0.5.2」。
- 单条 140 字左右，超出拆成串推。不加粗，不用小标题。

## 禁忌

- 教程腔，营销腔（「重磅」「炸裂」「建议收藏」）。
- 堆形容词。用事实和数字代替。
- 替读者下结论。态度只放在开头一句和结尾表情里。

## 示例

```text
被全黑视频坑过的，这版能省不少时间。

拉片笔记 v0.5.2 今天上线，开头连续 30 帧纯黑，就直接停下提醒你先转码，不再白抽几千帧。

而且字幕明显比片子长的，现在导入就会提示，一键裁掉 🙃
```
