# BK 原则提炼项目

把 BK（导演BK / BBKinG）过去二十多年公开表达过的判断，挖成 100 条候选，再压成 20 条「BK 原则」。目标：让之后所有热点内容都往这 20 条母观点上生长，账号呈现出清晰的思想骨架。

## 文件

- [`01-候选判断100.md`](01-候选判断100.md) —— 100 条候选判断，按主题分组，每条附出处
- [`02-BK原则20.md`](02-BK原则20.md) —— 压缩后的 20 条原则，每条附：原则本体、展开、对应的候选判断编号、热点内容怎么往上挂

## 已知局限

- X、知乎、B 站在本次挖掘环境下无法直接抓取，推文和部分文章依赖搜索索引片段与第三方转述，标注了【原文】/【转述】/【推断】三档可信度，引用前建议核对原文。
- 「我们聊过的东西」（私下对话）不在本次语料内，只覆盖公开表达。
- 候选判断保留了 BK 不同时期的表述，个别观点他本人后来已公开修正（如移动电竞），这类条目单独标注——「公开认错」本身也是一条原则。
